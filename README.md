# Geog4/6300: Midterm data sprint

This is the repo for the final research sprint in Geog4/6300. It's your chance to practice the skills you've been learning related to spatial and statistical analysis and to get experience creating and implementing your own analysis workflow.

For this project, we will be using a tidytuesday dataset. We'll decide on the exact dataset as a class. You'll then have THREE DAYS to answer a relevant research question related to this dataset.

All of these datasets come with questions already suggested, so you are STRONGLY encouraged to use or adapt one of those. Use your own question if you must.

Then create a quarto markdown (qmd) file similar to your lab responses in which you answer that question. That qmd file should include the following:

* Introduction
	* A brief description of the dataset and its main variables. 
	* The research question you are trying to answer related to this dataset
* Analysis 
	* A section in which you answer that question using R coding skills you've learned. This will include code chunks as well as brief description of what each of those code chunks is doing.
	* This section should include at least *two visualizations* (graphs/maps) relevant to your research question.
* Discussion
	* Explains how you would answer your research question based on your analysis. Make specific reference to the results in your analysis section that support this answer.
* Tie to class
	* Explain how this exercise shows what you've learned in the class thus far, mentioning at least three relevant learning standards.

When you're done, knit/render the qmd document just as you did for the labs. Then upload/push your work back up to Github and post a link to your repo on ELC under Assignments.

To be marked as complete, you'll need to show a good faith effort to answer your research question and explain how your results (even if incomplete!) demonstrate at least three things you've learned in the class.
